# moonspec Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deploy a rabbita-based landing page and docs site for moonspec at <https://moonrockz.github.io/moonspec/>, with the released docs at `/moonspec/` and the `main` docs at `/moonspec/next/`.

**Architecture:** A separate MoonBit module in `site/`. Pure packages (`route`, `content`, `highlight`, `markdown`, `search`, `data`) hold all logic and are unit-tested. One rabbita component (`shell`) renders the whole `<html>` document. A native program (`prerender`) runs `App::render` for every route and writes static HTML. The browser bundle (`app`) hydrates that HTML and then works as an SPA. A native `linkcheck` program verifies the output. A GitHub Actions workflow builds both versions and deploys them to Pages.

**Tech Stack:** MoonBit toolchain 2026-10-12, `moonbit-community/rabbita@0.16.4`, `moonbit-community/cmark@0.4.12`, `moonbitlang/async@0.22.4`, `moonbitlang/x@0.5.5`, `moonbit-community/warren@0.4.5` (build tool), GitHub Actions, GitHub Pages.

**Spec:** `docs/plans/2026-10-13-site-design.md`. Read it before you start.

## Spec deviations (decided while planning)

| Spec says | Plan does | Why |
|---|---|---|
| Packages under `site/src/` | Packages at the top of `site/` (`site/route`, `site/app`, ...) | The warren template uses this layout, so `warren build --browser-entry app` works as documented. |
| Base, version and channel as data attributes on `<html>` | All site data in one `<meta name="ms-data" content="...">` (JSON) | Attribute values round-trip safely through HTML escaping. Script text does not. |
| Try `Yoorkin/shiki@0.1.0` for highlighting | Own small highlighter (`site/highlight`) | shiki highlights asynchronously in the browser, so the pre-rendered HTML would differ from the hydrated tree. |
| Version picker opens the docs index when the page is missing in the other version | Links to the same route; a missing page shows the 404 view, which links to the docs | The browser has only its own version's manifest. |
| Nav has "Docs" and "Guide" | Nav has "Docs" (getting started), "API ↗", "GitHub ↗" | "Docs" and "Guide" would open the same page. |
| "On this page" marks the current section | No current-section marking | It needs scroll tracking through FFI; left for later. |

## Review Focus

1. **Duplicate headings** ("Example" twice on one page): cmark gives both the id `example`. Expect `example` and `example-1` (GitHub style), so in-page links and TOC entries stay unique. Test: Task 5.
2. **Markdown text with `"`, `<`, `>`, `&`, `</script>`** in the site data: the page must show the exact text after hydration, and the pre-rendered HTML must stay valid. Test: Task 1 (spike) and Task 8.
3. **URL path shapes**: trailing slash, double slash, `index.html`, a base without its trailing slash (`/moonspec/next`), a path outside the base. Expect the same route for equivalent paths and "not mine" for foreign paths. Test: Task 2.
4. **Search input edge cases**: empty, whitespace only, punctuation only (`--`), mixed case, non-ASCII (`Ünïcode`). Expect no results (not a crash) for empty input and case-insensitive matches otherwise. Test: Task 7.
5. **An older release tag without `docs/migrations/`** or without a newer guide: expect the build to succeed and that version's sidebar to omit the missing pages. Test: Task 3 and Task 11.

```moonbit
  title : String
  body : String
} derive(Eq, Debug, ToJson, FromJson)

///|
pub extend SpikeData with Eq::{equal, not_equal}

///|
pub extend SpikeData with @moonbitlang/core/debug.Debug::{to_repr}

pub extend SpikeData with ToJson::{to_json}

pub extend SpikeData with FromJson::{from_json}

/// pre-render and the browser pass the same string, so both build the same
/// tree.
pub fn spike_component(data : SpikeData, json : String) -> @rabbita.Val[Html] {
  let (count, emit) = @rabbita.create_pure_state(0, update=(n, _msg : Unit) => {
    n + 1
  })
  count.map(n => {
    html(lang="en", [
      head([
        meta(charset="utf-8"),
        title(data.title),
        meta(name="ms-data", content=json),
        script(src=data.base + "index.js", type_="module", ([] : Array[Html])),
      ]),
      body([
        h1(data.title),
        p(id="spike-body", data.body),
        button(id="spike-btn", on_click=emit(()), "clicks: \{n}"),
      ]),
    ])
  })
}
```

```moonbit
///|
/// The guide that `/docs/` opens.
pub let default_doc_slug : String = "getting-started"

///|
/// A page of the site, without the base path.
pub(all) enum Route {
  Landing
  Doc(String)
  Migration(String)
  NotFound(String)
} derive(Eq, Debug, ToJson, FromJson)

///|
pub extend Route with Eq::{equal, not_equal}

///|
pub extend Route with @moonbitlang/core/debug.Debug::{to_repr}

///|
pub extend Route with ToJson::{to_json}

///|
pub extend Route with FromJson::{from_json}

///|
/// Non-empty path segments; a trailing `index.html` is dropped.
fn segments(path : String) -> Array[String] {
  let out : Array[String] = []
  for part in path.split("/") {
    let s = part.to_owned()
    if s != "" {
      out.push(s)
    }
  }
  if out.last() == Some("index.html") {
    ignore(out.pop())
  }
  out
}

///|
/// Route of a path after the base path, for example `docs/configuration`.
pub fn Route::parse(path : String) -> Route {
  let segs = segments(path)
  match segs {
    [] => Landing
    ["docs"] => Doc(default_doc_slug)
    ["docs", slug] => Doc(slug)
    ["migrations", version] => Migration(version)
    _ => NotFound(segs.join("/"))
  }
}

///|
/// The path of the route after the base path, without leading or trailing `/`.
pub fn Route::to_path(self : Route) -> String {
  match self {
    Landing => ""
    Doc(slug) => "docs/" + slug
    Migration(version) => "migrations/" + version
    NotFound(path) => path
  }
}

///|
/// The URL path of `route` under `base` (which ends with `/`).
pub fn href(base : String, route : Route) -> String {
  base + route.to_path()
}

///|
/// The part of an URL path after `base`, or `None` when the path is not under
/// `base`. `path` may lack its leading `/` (rabbita's `Url.path` does).
pub fn strip_base(base : String, path : String) -> String? {
  let p = if path.has_prefix("/") { path } else { "/" + path }
  if p.has_prefix(base) {
    Some(p[base.length():].to_owned())
  } else if p + "/" == base {
    Some("")
  } else {
    None
  }
}
```

```moonbit
/// A repository path without a leading `./`.
pub fn normalize_path(path : String) -> String {

///|
fn is_slug(s : String) -> Bool {
  s != "" &&
  s.iter().all(c => (c >= 'a' && c <= 'z') || (c >= '0' && c <= '9') || c == '-')
}

///|
/// `[major, minor, patch]` of `vX.Y.Z`, or `None`.
fn version_numbers(v : String) -> Array[Int]? {
  guard v.has_prefix("v") else { return None }
  let out : Array[Int] = []
  for part in v[1:].split(".") {
    let s = part.to_owned()
    guard s != "" && s.iter().all(c => c >= '0' && c <= '9') else { return None }
    let mut n = 0
    for c in s {
      n = n * 10 + (c.to_int() - '0'.to_int())
    }
    out.push(n)
  }
  if out.length() == 3 {
    Some(out)
  } else {
    None
  }
}

///|
/// Compares `vX.Y.Z` strings numerically. Invalid versions sort first.
pub fn compare_versions(a : String, b : String) -> Int {
  match (version_numbers(a), version_numbers(b)) {
    (Some(x), Some(y)) =>
      if x[0] != y[0] {
        x[0] - y[0]
      } else if x[1] != y[1] {
        x[1] - y[1]
      } else {
        x[2] - y[2]
      }
    (None, Some(_)) => -1
    (Some(_), None) => 1
    (None, None) => a.compare(b)
  }
}

///|
/// The route and group of a published source file, or `None` when the file
/// is not published (for example anything under `docs/plans/`).
pub fn classify(path : String) -> (@route.Route, Group)? {
  let p = normalize_path(path)
  guard p.has_suffix(".md") else { return None }
  let segs = p[:p.length() - 3].split("/").map(s => s.to_owned()).collect()
  match segs {
    ["docs", "guide", slug] if is_slug(slug) => Some((Doc(slug), Guides))
    ["docs", "migrations", version] if version_numbers(version) is Some(_) =>
      Some((Migration(version), Migrations))
    _ => None
  }
}

///|
fn guide_rank(route : @route.Route) -> (Int, String) {
  match route {
    Doc(slug) =>
      match guide_order.search(slug) {
        Some(i) => (i, slug)
        None => (guide_order.length(), slug)
      }
    _ => (guide_order.length(), "")
  }
}

///|
fn migration_version(route : @route.Route) -> String {
  match route {
    Migration(v) => v
    _ => ""
  }
}

///|
/// The manifest of the published files among `files`.
pub fn Manifest::build(files : Array[SourceFile]) -> Manifest {
  let guides : Array[Page] = []
  let migrations : Array[Page] = []
  for f in files {
    match classify(f.path) {
      Some((route, Guides)) =>
        guides.push({ route, title: f.title, source: normalize_path(f.path), group: Guides })
      Some((route, Migrations)) =>
        migrations.push({
          route,
          title: f.title,
          source: normalize_path(f.path),
          group: Migrations,
        })
      None => ()
    }
  }
  guides.sort_by((a, b) => {
    let (ra, sa) = guide_rank(a.route)
    let (rb, sb) = guide_rank(b.route)
    if ra != rb {
      ra - rb
    } else {
      sa.compare(sb)
    }
  })
  migrations.sort_by((a, b) => {
    compare_versions(migration_version(b.route), migration_version(a.route))
  })
  { pages: [..guides, ..migrations] }
}

///|
pub fn Manifest::find(self : Manifest, route : @route.Route) -> Page? {
  for page in self.pages {
    if page.route == route {
      return Some(page)
    }
  }
  None
}

///|
pub fn Manifest::find_source(self : Manifest, source : String) -> Page? {
  let wanted = normalize_path(source)
  for page in self.pages {
    if page.source == wanted {
      return Some(page)
    }
  }
  None
}

///|
/// The pages before and after `route` in sidebar order.
pub fn Manifest::neighbors(
  self : Manifest,
  route : @route.Route,
) -> (Page?, Page?) {
  for i, page in self.pages {
    if page.route == route {
      let prev = if i > 0 { Some(self.pages[i - 1]) } else { None }
      let next = if i + 1 < self.pages.length() {
        Some(self.pages[i + 1])
      } else {
        None
      }
      return (prev, next)
    }
  }
  (None, None)
}
```

```moonbit
///|
/// Index after a string literal that starts at `i` (a `"`). Stops at the end
/// of the line when the string is not closed.
fn string_end(s : Array[Char], i : Int) -> Int {
  let mut j = i + 1
  while j < s.length() && s[j] != '\n' {
    if s[j] == '\\' && j + 1 < s.length() {
      j = j + 2
      continue
    }
    if s[j] == '"' {
      return j + 1
    }
    j = j + 1
  }
  j
}

///|
fn line_end(s : Array[Char], i : Int) -> Int {
  let mut j = i
  while j < s.length() && s[j] != '\n' {

}

///|
fn scan_moonbit(s : Array[Char], out : Out) -> Unit {
  let mut i = 0
  while i < s.length() {
    let c = s[i]
    if c == '/' && i + 1 < s.length() && s[i + 1] == '/' {
      let e = line_end(s, i)
      out.push(Comment, slice(s, i, e))
      i = e
    } else if c == '#' && i + 1 < s.length() && s[i + 1] == '|' {
      let e = line_end(s, i)
      out.push(Str, slice(s, i, e))
      i = e
    } else if c == '#' && i + 1 < s.length() && is_ident_char(s[i + 1]) {
      let mut j = i + 1
      while j < s.length() && (is_ident_char(s[j]) || s[j] == '.') {
        j = j + 1
      }
      out.push(Tag, slice(s, i, j))
      i = j
    } else if c == '"' {
      let e = string_end(s, i)
      out.push(Str, slice(s, i, e))
      i = e
    } else if is_digit(c) {
      let mut j = i
      while j < s.length() && (is_digit(s[j]) || s[j] == '_' || s[j] == '.') {
        j = j + 1
      }
      out.push(Number, slice(s, i, j))
      i = j
    } else if is_ident_char(c) {
      let mut j = i
      while j < s.length() && is_ident_char(s[j]) {
        j = j + 1

      out.push(if moonbit_keywords.contains(word) { Keyword } else { Plain }, word)
      i = j
    } else {
      out.push(Plain, slice(s, i, i + 1))
      i = i + 1
    }
  }
}

/// Strings and numbers inside one Gherkin step or table line.
fn scan_gherkin_rest(s : Array[Char], from : Int, to : Int, out : Out) -> Unit {
  let mut i = from
  while i < to {
    let c = s[i]
    if c == '"' {
      let e = @cmp.minimum(string_end(s, i), to)
      out.push(Str, slice(s, i, e))
      i = e
    } else if is_digit(c) && (i == from || !is_ident_char(s[i - 1])) {
      let mut j = i
      while j < to && (is_digit(s[j]) || s[j] == '.') {
        j = j + 1
      }
      out.push(Number, slice(s, i, j))
      i = j
    } else {
      out.push(Plain, slice(s, i, i + 1))
      i = i + 1
    }
  }
}

///|
fn scan_gherkin(s : Array[Char], out : Out) -> Unit {
  let mut i = 0
  while i < s.length() {
    let e = line_end(s, i)
    let mut j = i
    while j < e && (s[j] == ' ' || s[j] == '\t') {
      j = j + 1
    }
    out.push(Plain, slice(s, i, j))
    let rest = slice(s, j, e)
    if rest.has_prefix("#") {
      out.push(Comment, rest)
    } else if rest.has_prefix("@") {
      let mut k = j
      while k < e {
        if s[k] == '@' {
          let mut m = k
          while m < e && s[m] != ' ' {
            m = m + 1
          }
          out.push(Tag, slice(s, k, m))
          k = m
        } else {
          out.push(Plain, slice(s, k, k + 1))
          k = k + 1
        }
      }
    } else {
      let mut matched = false
      for kw in gherkin_keywords {
        if rest.has_prefix(kw) &&
          (kw.has_suffix(":") || rest.length() == kw.length() || rest[kw.length()] == ' ') {
          out.push(Keyword, kw)
          scan_gherkin_rest(s, j + kw.length(), e, out)
          matched = true
          break
        }
      }
      if !matched {
        scan_gherkin_rest(s, j, e, out)
      }
    }
    if e < s.length() {
      out.push(Plain, "\n")
    }
    i = e + 1
  }
}

///|
fn scan_shell(s : Array[Char], out : Out) -> Unit {
  let mut i = 0
  while i < s.length() {
    let c = s[i]
    if c == '#' && (i == 0 || s[i - 1] == ' ' || s[i - 1] == '\n') {
      let e = line_end(s, i)
      out.push(Comment, slice(s, i, e))
      i = e
    } else if c == '"' || c == '\'' {
      let mut j = i + 1
      while j < s.length() && s[j] != c && s[j] != '\n' {
        j = j + 1
      }
      let e = if j < s.length() && s[j] == c { j + 1 } else { j }
      out.push(Str, slice(s, i, e))
      i = e
    } else {
      out.push(Plain, slice(s, i, i + 1))
      i = i + 1
    }
  }
}

pub fn highlight(lang : String, code : String) -> Array[Token] {

    "moonbit" | "mbt" => scan_moonbit(chars, out)

    "json" | "json5" | "jsonc" => scan_moonbit(chars, out)
    _ => out.push(Plain, code)
  }
  out.tokens
}
```

```moonbit
fn Conv::table(self : Conv, tbl : @cmark.Table) -> Block {
  let header : Array[Array[Inline]] = []
  let rows : Array[Array[Array[Inline]]] = []
  for item in tbl.rows.iter() {
    let (row, _) = item
    match row.v {
      Header(cells) =>
        for cell in cells.iter() {
          header.push(self.inlines(cell.0))
        }
      Data(cells) => {
        let out : Array[Array[Inline]] = []
        for cell in cells.iter() {
          out.push(self.inlines(cell.0))
        }
        rows.push(out)
      }
      Sep(_) => ()
    }
  }
  Table(header, rows)
}

///|
fn Conv::blocks(self : Conv, block : @cmark.Block) -> Array[Block] {
  match block {
    Blocks({ v: bs, .. }) => {
      let out : Array[Block] = []
      for b in bs.iter() {
        for x in self.blocks(b) {
          out.push(x)
        }
      }
      out
    }
    Heading({ v: { level, inline, id, .. }, .. }) => {
      let content = self.inlines(inline)
      let text = inline_text(content)
      let raw = match id {
        Some(Auto(s)) | Some(Id(s)) => s
        None => text.to_lower()
      }
      let unique = self.unique_id(raw)
      if level == 1 && self.title is None {
        self.title = Some(text)
      }
      if level == 2 || level == 3 {
        self.toc.push({ level, id: unique, text })
      }
      [Heading(level, unique, content)]
    }
    Paragraph({ v: { inline, .. }, .. }) => [Paragraph(self.inlines(inline))]
    CodeBlock({ v: cb, .. }) | ExtMathBlock({ v: cb, .. }) =>
      [CodeBlock(code_language(cb), code_source(cb))]
    BlockQuote({ v: { block: inner, .. }, .. }) => [Quote(self.blocks(inner))]
    List({ v: { ty, items, .. }, .. }) => {
      let xs : Array[Array[Block]] = []
      for item in items.iter() {
        xs.push(self.blocks(item.v.block))
      }
      match ty {
        Unordered(_) => [BulletList(xs)]
        Ordered(start, _) => [OrderedList(start, xs)]
      }
    }
    ThematicBreak(_) => [Rule]
    ExtTable({ v: tbl, .. }) => [self.table(tbl)]
    BlankLine(_)
    | HtmlBlock(_)
    | LinkRefDefinition(_)
    | ExtFootnoteDefinition(_) => []
  }
```

```moonbit
fn path_parts(path : String) -> Array[String] {
  path.split("/").map(s => s.to_owned()).collect()
}

///|
/// The repository path of `rel`, relative to the file `from_file`.
pub fn resolve_path(from_file : String, rel : String) -> String {
  let parts : Array[String] = []
  let dir = path_parts(from_file)
  ignore(dir.pop())
  for p in dir {
    if p != "" && p != "." {
      parts.push(p)
    }
  }
  for s in path_parts(rel) {
    match s {
      "" | "." => ()
      ".." => ignore(parts.pop())
      _ => parts.push(s)
    }
  }
  parts.join("/")
}

///|
fn is_absolute_url(dest : String) -> Bool {
  dest.contains("://") || dest.has_prefix("mailto:")
}

///|
fn split_anchor(dest : String) -> (String, String?) {
  match dest.find("#") {
    Some(i) => (dest[:i].to_owned(), Some(dest[i + 1:].to_owned()))
    None => (dest, None)
  }
}

///|
fn repo_path(dest_path : String, ctx : LinkContext) -> String {
  if dest_path.has_prefix("/") {
    resolve_path("", dest_path)
  } else {
    resolve_path(ctx.source, dest_path)
  }
}

///|
fn github_url(ctx : LinkContext, path : String, anchor : String?) -> String {
  let last = path_parts(path).last().unwrap_or("")
  let kind = if last.contains(".") { "blob" } else { "tree" }
  let url = ctx.repo_url +
    "/" +
    kind +
    "/" +
    ctx.git_ref +
    (if path == "" { "" } else { "/" + path })
  match anchor {
    Some(a) => url + "#" + a
    None => url
  }
}

///|
/// Rewrites a Markdown link destination for the site.
pub fn rewrite_link(dest : String, ctx : LinkContext) -> Target {
  if dest.has_prefix("#") {
    return Anchor(dest[1:].to_owned())
  }
  if is_absolute_url(dest) {
    return External(dest)
  }
  let (path, anchor) = split_anchor(dest)
  let target = repo_path(path, ctx)
  if target.has_suffix(".md") {
    match (ctx.resolve)(target) {
      Some(route) => return Internal(route, anchor)
      None => ()
    }
  }
  External(github_url(ctx, target, anchor))
}

///|
/// The URL of an image: absolute URLs stay; repository paths load from raw GitHub.
pub fn image_src(dest : String, ctx : LinkContext) -> String {
  if is_absolute_url(dest) {
    return dest
  }
  let raw_root = if ctx.repo_url.has_prefix("https://github.com/") {
    "https://raw.githubusercontent.com/" + ctx.repo_url["https://github.com/".length():].to_owned()
  } else {
    ctx.repo_url
  }
  raw_root + "/" + ctx.git_ref + "/" + repo_path(dest, ctx)
}
```

```moonbit
fn Acc::flush(self : Acc) -> Unit {
  let text = self.parts.filter(p => p != "").join(" ")
  if text != "" || self.path.length() > 0 {
    self.out.push({
      route: self.route,
      anchor: self.anchor,
      page: self.page,
      path: self.path,
      text,
    })
  }
  self.parts.clear()
}

///|
/// The search entries of one page.
pub fn entries_for(
  page : String,
  route : @route.Route,
  doc : @markdown.Document,
) -> Array[Entry] {
  let acc = Acc::{ page, route, out: [], parts: [], anchor: "", path: [], h2: "" }
  for block in doc.blocks {
    match block {
      Heading(1, _, _) => ()
      Heading(2, id, xs) => {
        acc.flush()
        let text = @markdown.inline_text(xs)
        acc.h2 = text
        acc.anchor = id
        acc.path = [text]
      }
      Heading(3, id, xs) => {
        acc.flush()
        let text = @markdown.inline_text(xs)
        acc.anchor = id
        acc.path = if acc.h2 == "" { [text] } else { [acc.h2, text] }
      }
      other => acc.parts.push(@markdown.block_text(other))
    }
  }
  acc.flush()
  acc.out
}

///|
fn is_word_char(c : Char) -> Bool {
  (c >= 'a' && c <= 'z') || (c >= '0' && c <= '9') || c.to_int() > 127
}

///|
/// Lower-case words; punctuation, `_` and `-` separate words.
pub fn tokenize(s : String) -> Array[String] {
  let out : Array[String] = []
  let cur : Array[Char] = []
  for c in s.to_lower() {
    if is_word_char(c) {
      cur.push(c)
    } else if cur.length() > 0 {
      out.push(String::from_array(cur))
      cur.clear()
    }
  }
  if cur.length() > 0 {
    out.push(String::from_array(cur))
  }
  out
}

fn has_prefix_token(tokens : Array[String], term : String) -> Bool {
  tokens.iter().any(t => t.has_prefix(term))
}

///|
/// Results for `query`, best first. Weights: page title 8, heading 4,
/// text 1; +100 when every query term matches.
pub fn search(index : Index, query : String, limit? : Int = 20) -> Array[Match] {
  let terms = tokenize(query)
  if terms.is_empty() {
    return []
  }
  let scored : Array[(Int, Int, Entry)] = []
  for i, p in index.items {
    let mut score = 0
    let mut matched = 0
    for t in terms {
      let w = if has_prefix_token(p.title, t) {
        8
      } else if has_prefix_token(p.heading, t) {
        4
      } else if has_prefix_token(p.text, t) {
        1
      } else {
        0
      }
      if w > 0 {
        score = score + w
        matched = matched + 1
      }
    }
    if score > 0 {
      let total = if matched == terms.length() { score + 100 } else { score }
      scored.push((total, i, p.entry))
    }
  }
  scored.sort_by((a, b) => if a.0 != b.0 { b.0 - a.0 } else { a.1 - b.1 })
  let n = if scored.length() < limit { scored.length() } else { limit }
  let out : Array[Match] = []
  for k = 0; k < n; k = k + 1 {
    let (score, _, entry) = scored[k]
    out.push({ entry, score, excerpt: excerpt(entry.text, terms) })
  }
  out
}

///|
/// Up to about 120 characters of `text` around the first match, with every
/// word that starts with a term marked.
pub fn excerpt(text : String, terms : Array[String]) -> Array[Segment] {
  let lower = text.to_lower()
  let mut first = -1
  for t in terms {
    match lower.find(t) {
      Some(i) => if first < 0 || i < first { first = i }
      None => ()
    }
  }
  let start = if first <= 30 { 0 } else { first - 30 }
  let end = if start + 120 < text.length() { start + 120 } else { text.length() }
  let out : Array[Segment] = []
  if start > 0 {
    out.push(Plain("…"))
  }
  let chars = text.to_array()
  let lchars = lower.to_array()
  let plain : Array[Char] = []
  let mut i = start
  while i < end {
    let at_word_start = i == 0 || !is_word_char(lchars[i - 1])
    let mut hit = 0
    if at_word_start {
      for t in terms {
        let tc = t.to_array()
        if i + tc.length() <= lchars.length() &&
          String::from_array(lchars[i:i + tc.length()].to_array()) == t {
          hit = tc.length()
          break
        }
      }
    }
    if hit > 0 {
      if plain.length() > 0 {
        out.push(Plain(String::from_array(plain)))
        plain.clear()
      }
      out.push(Hit(String::from_array(chars[i:i + hit].to_array())))
      i = i + hit
    } else {
      plain.push(chars[i])
      i = i + 1
    }
  }
  if plain.length() > 0 {
    out.push(Plain(String::from_array(plain)))
  }
  if end < text.length() {
    out.push(Plain("…"))
  }
  out
}

///|
/// Matches grouped by page title, in first-seen order.
pub fn group_by_page(matches : Array[Match]) -> Array[(String, Array[Match])] {
  let out : Array[(String, Array[Match])] = []
  for m in matches {
    match out.search_by(g => g.0 == m.entry.page) {
      Some(i) => out[i].1.push(m)
      None => out.push((m.entry.page, [m]))
    }
  }
  out
}
```

`text.find` and `text.length()` count UTF-16 code units, while `to_array` counts characters. The docs are almost all ASCII. If a test with non-ASCII text fails, compute `first` on `lchars` (a character array) instead of `lower.find`. If `Array::search_by` does not exist, use a `for` loop over `out`.

```moonbit
///|
fn open_search(m : Model, emit : @rabbita.Emit[Msg]) -> (Model, @rabbita.Cmd) {
  let focus_cmd = @rabbita.effect(async fn() noraise { focus("ms-search-input") })
  match m.search.index {
    NotLoaded | IndexFailed => {
      let search = { ..m.search, open: true, selected: 0, index: LoadingIndex }
      let load = @http.get(m.config.base + "search-index.json").expect_text(
        emit.map(r => IndexLoaded(r)),
      )

    }
    _ => ({ ..m, search: { ..m.search, open: true, selected: 0 } }, focus_cmd)
  }

///|
fn on_url_changed(
  m : Model,
  url : @url.Url,
  emit : @rabbita.Emit[Msg],
) -> (Model, @rabbita.Cmd) {
  guard @route.strip_base(m.config.base, url.path) is Some(rest) else {
    return (m, @rabbita.none)
  }
  let route = @route.Route::parse(rest)
  let scroll = match url.fragment {
    Some(id) if id != "" => @nav.scroll_to(id)
    _ => @nav.scroll_to_top()
  }
  let closed = { ..m, search: { ..m.search, open: false }, menu_open: false }
  if route == m.route {
    return (closed, scroll)
  }
  let next = { ..closed, route }
  match m.manifest.find(route) {
    Some(page) =>
      ({ ..next, page: Loading }, @rabbita.batch([fetch_page(m.config, page, emit), scroll]))
    None => ({ ..next, page: NoContent }, @nav.scroll_to_top())
  }
}

///|
pub fn update(
  m : Model,
  msg : Msg,
  emit : @rabbita.Emit[Msg],
) -> (Model, @rabbita.Cmd) {
  match msg {
    UrlChanged(url) => on_url_changed(m, url, emit)
    UrlRequested(Internal(url)) =>
      if @route.strip_base(m.config.base, url.path) is Some(_) {
        (m, @nav.push_url(url_href(url)))
      } else {
        // Another version of the site: a full page load.
        (m, @nav.load(url_href(url)))
      }
    UrlRequested(External(href)) => (m, @nav.load(href))
    ContentLoaded(route, result) => {
      guard route == m.route else { return (m, @rabbita.none) }
      let page = match result {
        Ok(md) => Ready(parse_page(m.config, m.manifest, route, md))
        Err(_) => PageFailed
      }
      ({ ..m, page }, @rabbita.none)
    }
    ThemeLoaded(theme) => ({ ..m, theme }, @rabbita.none)
    ToggleTheme => {
      let theme = match m.theme {
        Auto => Dark
        Dark => Light
        Light => Auto
      }
      ({ ..m, theme }, @rabbita.effect(async fn() noraise { store_theme(theme) }))
    }
    OpenSearch => open_search(m, emit)
    CloseSearch => ({ ..m, search: { ..m.search, open: false } }, @rabbita.none)
    SearchInput(query) =>
      ({ ..m, search: { ..m.search, query, selected: 0 } }, @rabbita.none)
    IndexLoaded(Ok(text)) => {
      let index = match parse_index(text) {
        Some(entries) => IndexReady(@search.Index::new(entries))
        None => IndexFailed
      }
      ({ ..m, search: { ..m.search, index } }, @rabbita.none)
    }
    IndexLoaded(Err(_)) =>
      ({ ..m, search: { ..m.search, index: IndexFailed } }, @rabbita.none)
    MoveSelection(delta) => {
      let count = flat_results(m).length()
      let selected = if count == 0 {
        0
      } else {
        (m.search.selected + delta + count) % count
      }
      ({ ..m, search: { ..m.search, selected } }, @rabbita.none)
    }
    OpenSelected =>
      match flat_results(m).get(m.search.selected) {
        Some(hit) =>
          ({ ..m, search: { ..m.search, open: false } }, @nav.push_url(entry_href(m.config, hit.entry)))
        None => (m, @rabbita.none)
      }
    KeyDown(key) => on_key(m, key, emit)
    SelectTab(tab) => ({ ..m, install_tab: tab }, @rabbita.none)
    ToggleMenu => ({ ..m, menu_open: !m.menu_open }, @rabbita.none)
  }
}

///|
fn parse_index(text : String) -> Array[@search.Entry]? {
  let json = @json.parse(text) catch { _ => return None }
  let entries : Array[@search.Entry] = @json.from_json(json) catch {
    _ => return None
  }
  Some(entries)
}

///|
fn on_key(
  m : Model,
  key : @common.Keyboard,
  emit : @rabbita.Emit[Msg],
) -> (Model, @rabbita.Cmd) {
  let k = key.key()
  if !m.search.open {
    if (k == "k" || k == "K") && (key.meta_key() || key.ctrl_key()) || k == "/" {
      return open_search(m, emit)
    }
    return (m, @rabbita.none)
  }
  match k {
    "Escape" => update(m, CloseSearch, emit)
    "ArrowDown" => update(m, MoveSelection(1), emit)
    "ArrowUp" => update(m, MoveSelection(-1), emit)
    "Enter" => update(m, OpenSelected, emit)
    _ => (m, @rabbita.none)
  }
}
```

```moonbit
fn md_block(base : String, b : @markdown.Block) -> Html {
  match b {
    Heading(level, id, xs) => {
      let attrs = @html.Attrs::build().id(id)
      let kids = [
        ..md_inlines(base, xs),
        @html.a(class="ms-anchor", href="#" + id, "#"),
      ]
      match level {
        1 => @html.h1(attrs~, kids)
        2 => @html.h2(attrs~, kids)
        3 => @html.h3(attrs~, kids)
        4 => @html.h4(attrs~, kids)
        5 => @html.h5(attrs~, kids)
        _ => @html.h6(attrs~, kids)
      }
    }
    Paragraph(xs) => @html.p(md_inlines(base, xs))
    CodeBlock(lang, code) => code_view(lang, code)
    Quote(bs) => @html.blockquote(bs.map(x => md_block(base, x)))
    BulletList(items) =>
      @html.ul(items.map(item => @html.li(item.map(x => md_block(base, x)))))
    OrderedList(start, items) =>
      @html.ol(start~, items.map(item => @html.li(item.map(x => md_block(base, x)))))
    Table(header, rows) =>
      @html.div(class="ms-table-wrap", [
        @html.table([
          @html.thead([@html.tr(header.map(c => @html.th(md_inlines(base, c))))]),
          @html.tbody(
            rows.map(r => @html.tr(r.map(c => @html.td(md_inlines(base, c))))),
          ),
        ]),
      ])
    Rule => @html.hr()
  }
}
```

```moonbit
fn excerpt_view(segments : Array[@search.Segment]) -> Array[Html] {
  segments.map(s => {
    match s {
      Plain(t) => @html.text(t)
      Hit(t) => @html.mark(t)

///|
fn search_view(m : Model, emit : @rabbita.Emit[Msg]) -> Html {
  if !m.search.open {
    return @html.nothing
  }
  let groups = current_results(m)
  let mut position = 0
  let body : Array[Html] = []
  match m.search.index {
    LoadingIndex | NotLoaded => body.push(@html.p(class="ms-search-note", "Loading search…"))
    IndexFailed =>
      body.push(
        @html.p(class="ms-search-note", [
          @html.text("Search is not available. "),
          @html.a(href=@route.href(m.config.base, Doc(@route.default_doc_slug)), "Open the docs"),
        ]),
      )
    IndexReady(_) =>
      if m.search.query.trim(chars=" ").is_empty() {
        body.push(@html.p(class="ms-search-note", "Type to search the \{m.config.version} docs."))
      } else if groups.is_empty() {
        body.push(@html.p(class="ms-search-note", "No results for “\{m.search.query}”."))
      } else {
        for group in groups {
          body.push(@html.p(class="ms-search-group", group.0))
          for hit in group.1 {
            let title = if hit.entry.path.is_empty() {
              hit.entry.page
            } else {
              hit.entry.path.join(" › ")
            }
            body.push(
              @html.a(
                class=class_if("ms-search-item", "ms-search-selected", position == m.search.selected),
                href=entry_href(m.config, hit.entry),
                [
                  @html.span(class="ms-search-title", title),
                  @html.span(class="ms-search-excerpt", excerpt_view(hit.excerpt)),
                ],
              ),
            )
            position = position + 1
          }
        }
      }
  }
  @html.fragment([
    @html.div(class="ms-search-backdrop", on_click=emit(CloseSearch), ([] : Array[Html])),
    @html.div(
      class="ms-search",
      attrs=@html.Attrs::build().role("dialog").aria_label("Search docs"),
      [
        @html.input(
          id="ms-search-input",
          class="ms-search-input",
          placeholder="Search docs",
          value=m.search.query,
          on_input=emit.map(q => SearchInput(q)),
        ),
        @html.div(class="ms-search-results", body),
        @html.div(class="ms-search-hint", [
          @html.span("↑↓ move"),
          @html.span("↵ open"),
          @html.span("esc close"),
          @html.span(class="ms-search-scope", "Searching \{m.config.version}"),
        ]),
      ],
    ),
  ])
}
```

```moonbit
///|
pub(all) struct Args {
  content : String
  channel : @data.Channel
  site_root : String
  release_version : String
  git_ref : String
  out : String
} derive(Eq, Debug)

///|
pub extend Args with Eq::{equal, not_equal}

///|
pub extend Args with @moonbitlang/core/debug.Debug::{to_repr}

///|
fn with_slashes(path : String) -> String {
  let p = if path.has_prefix("/") { path } else { "/" + path }
  if p.has_suffix("/") {
    p
  } else {
    p + "/"
  }
}

///|
/// Parses the command line (`argv[0]` is the program name).
pub fn parse_args(argv : Array[String]) -> Result[Args, String] {
  let mut args : Args = {
    content: ".",
    channel: Next,
    site_root: "/moonspec/",
    release_version: "v0.0.0",
    git_ref: "main",
    out: "dist",
  }
  let mut i = 1
  while i < argv.length() {
    guard i + 1 < argv.length() else { return Err("missing value for \{argv[i]}") }
    let value = argv[i + 1]
    match argv[i] {
      "--content" => args = { ..args, content: value }
      "--channel" =>
        match value {
          "release" => args = { ..args, channel: Release }
          "next" => args = { ..args, channel: Next }
          _ => return Err("--channel must be release or next, got \{value}")
        }
      "--site-root" => args = { ..args, site_root: with_slashes(value) }
      "--release-version" => args = { ..args, release_version: value }
      "--ref" => args = { ..args, git_ref: value }
      "--out" => args = { ..args, out: value }
      flag => return Err("unknown flag \{flag}")
    }
    i = i + 2
  }
  Ok(args)
}

///|

  let release_base = with_slashes(args.site_root)
  let next_base = release_base + "next/"

    Release =>

        base: release_base,
        version: args.release_version,
        channel: Release,
        git_ref: args.git_ref,
        release_base,
        next_base,
        release_version: args.release_version,
      }
    Next =>
      {
        base: next_base,
        version: "next",
        channel: Next,
        git_ref: args.git_ref,
        release_base,
        next_base,
        release_version: args.release_version,
      }
  }
}
```

```moonbit
fn dirname(path : String) -> String {
  match path.rev_find("/") {
    Some(i) => path[:i].to_owned()

///|
fn ensure_dir(dir : String) -> Unit {
  if dir == "." || dir == "" || dir == "/" || @fs.path_exists(dir) {
    return
  }
  ensure_dir(dirname(dir))
  @fs.create_dir(dir) catch {
    _ => ()
  }
}

///|
fn write_file(path : String, content : String) -> Unit raise {
  ensure_dir(dirname(path))
  @fs.write_string_to_file(path, content)
}

///|
/// Markdown files under `dir`, as (repository path, text).
fn read_markdown_dir(content : String, dir : String) -> Array[(String, String)] raise {
  let full = content + "/" + dir
  if !@fs.path_exists(full) {
    return []
  }
  let names = @fs.read_dir(full)
  names.sort()
  let out : Array[(String, String)] = []
  for name in names {
    if name.has_suffix(".md") {
      out.push((dir + "/" + name, @fs.read_file_to_string(full + "/" + name)))
    }
  }
  out
}

///|
async fn render_page(data : @data.SiteData) -> String {
  let json = data.encode()
  let html = @rabbita.new(() => @shell.component(data, json)).render(
    url="http://localhost" + @route.href(data.config.base, data.route),
  )
  if html.has_prefix("<!DOCTYPE") || html.has_prefix("<!doctype") {
    html
  } else {
    "<!DOCTYPE html>\n" + html
  }
}

///|
/// Builds one version of the site into `args.out`.
pub async fn build_site(args : Args) -> Unit {
  let config = config_of(args)
  let files = [
    ..read_markdown_dir(args.content, "docs/guide"),
    ..read_markdown_dir(args.content, "docs/migrations"),
  ]
  let manifest = @content.Manifest::build(
    files.map(f => { path: f.0, title: @markdown.title_of(f.1) }),
  )
  let texts : Map[String, String] = {}
  for f in files {
    texts.set(f.0, f.1)
  }
  let entries : Array[@search.Entry] = []
  let routes : Array[String] = [""]
  // Landing page
  write_file(
    args.out + "/index.html",
    render_page({ config, pages: manifest.pages, route: Landing, markdown: None }),
  )
  // Published pages
  for page in manifest.pages {
    let text = texts.get(page.source).unwrap_or("")
    write_file(
      args.out + "/" + page_path(page.route),
      render_page({ config, pages: manifest.pages, route: page.route, markdown: Some(text) }),
    )
    write_file(args.out + "/content/" + page.source, text)
    let doc = @markdown.parse(text, @data.link_context(config, manifest, page.source))
    for e in @search.entries_for(page.title, page.route, doc) {
      entries.push(e)
    }
    routes.push(page.route.to_path())
  }
  // 404
  write_file(
    args.out + "/404.html",
    render_page({ config, pages: manifest.pages, route: NotFound("404"), markdown: None }),
  )
  write_file(args.out + "/search-index.json", entries.to_json().stringify())
  write_file(args.out + "/routes.json", routes.to_json().stringify())
  println("Built \{routes.length()} pages for \{config.version} at \{config.base} into \{args.out}")
}
```

```moonbit
///|
fn decode_entities(s : String) -> String {
  s.replace_all(old="&amp;", new="&")
}

///|
/// Values of `href="..."` and `src="..."` attributes, in document order.
pub fn extract_links(html : String) -> Array[String] {
  let out : Array[String] = []
  let chars = html.to_array()
  let mut i = 0
  while i < chars.length() {
    let rest = String::from_array(chars[i:@cmp.minimum(i + 6, chars.length())].to_array())
    let skip = if rest.has_prefix("href=\"") {
      6
    } else if rest.has_prefix("src=\"") {
      5
    } else {
      0
    }
    if skip > 0 {
      let start = i + skip
      let mut j = start
      while j < chars.length() && chars[j] != '"' {
        j = j + 1
      }
      out.push(decode_entities(String::from_array(chars[start:j].to_array())))
      i = j + 1
    } else {
      i = i + 1
    }
  }
  out
}

///|
/// The site path of an internal link (after `base`, without `#` or `?`), or
/// `None` for external, same-page and ignored links.
pub fn internal_path(base : String, ignore : Array[String], link : String) -> String? {
  guard link.has_prefix(base) else { return None }
  for prefix in ignore {
    if link.has_prefix(prefix) {
      return None
    }
  }
  let mut path = link[base.length():].to_owned()
  match path.find("#") {
    Some(k) => path = path[:k].to_owned()
    None => ()
  }
  match path.find("?") {
    Some(k) => path = path[:k].to_owned()
    None => ()
  }
  Some(path)
}

///|
/// The file, relative to `dist`, that serves the site path `path`.
pub fn target_file(path : String) -> String {
  if path == "" {
    return "index.html"
  }
  if path.has_suffix("/") {
    return path + "index.html"
  }
  let last = path.split("/").map(s => s.to_owned()).collect().last().unwrap_or("")
  if last.contains(".") {
    path
  } else {
    path + "/index.html"
  }
}

///|
fn html_files(dir : String, rel : String, out : Array[String]) -> Unit raise {
  for name in @fs.read_dir(dir) {
    let full = dir + "/" + name
    let relative = if rel == "" { name } else { rel + "/" + name }
    if @fs.is_dir(full) {
      html_files(full, relative, out)
    } else if name.has_suffix(".html") {
      out.push(relative)
    }
  }
}

///|
/// All problems found in `dist`; empty when the build is consistent.
pub fn check(dist : String, base : String, ignore : Array[String]) -> Array[String] raise {
  let problems : Array[String] = []
  let pages : Array[String] = []
  html_files(dist, "", pages)
  for page in pages {
    let html = @fs.read_file_to_string(dist + "/" + page)
    for link in extract_links(html) {
      match internal_path(base, ignore, link) {
        Some(path) =>
          if !@fs.path_exists(dist + "/" + target_file(path)) {
            problems.push("\{page}: broken link \{link}")
          }
        None => ()
      }
    }
  }
  let routes : Array[String] = @json.from_json(
    @json.parse(@fs.read_file_to_string(dist + "/routes.json")),
  )
  let entries : Array[@search.Entry] = @json.from_json(
    @json.parse(@fs.read_file_to_string(dist + "/search-index.json")),
  )
  for route in routes {
    if !@fs.path_exists(dist + "/" + target_file(route)) {
      problems.push("route \{route} has no HTML file")
    }
    if route != "" && !entries.iter().any(e => e.route.to_path() == route) {
      problems.push("route \{route} is not in the search index")
    }
  }
  if !@fs.path_exists(dist + "/404.html") {
    problems.push("404.html is missing")
  }
  problems
}
```

```yaml
      - name: Install dependencies
        run: |
          moon update
          moon install moonbit-community/warren@0.4.5

      - name: Check out the latest release
        id: release
        run: |
          tag=$(git tag --list 'v*' --sort=-v:refname | head -1)
          echo "tag=$tag" >> "$GITHUB_OUTPUT"
          git worktree add ../release "$tag"

      - name: Build the release docs
        run: >
          mise run site:build -- --content ../release --channel release
          --site-root /moonspec/ --release-version ${{ steps.release.outputs.tag }}
          --ref ${{ steps.release.outputs.tag }} --out _site

      - name: Build the main docs
        run: |
          mise run site:build -- --content . --channel next \
            --site-root /moonspec/ --release-version ${{ steps.release.outputs.tag }} \
            --ref "$(git rev-parse HEAD)" --out _site/next

      - name: Check links
        run: |
          mise run site:linkcheck -- --dist _site --base /moonspec/ --ignore /moonspec/next/
          mise run site:linkcheck -- --dist _site/next --base /moonspec/next/

      - uses: actions/configure-pages@<sha> # <tag>

      - uses: actions/upload-pages-artifact@<sha> # <tag>
        with:
          path: _site

      - id: deployment
        uses: actions/deploy-pages@<sha> # <tag>
```

The checkout uses `ref: main`, so `git rev-parse HEAD` is the `main` commit even for a `release` event (where `github.sha` is the tag commit).

````markdown
# moonspec site

The landing page and docs site at <https://moonrockz.github.io/moonspec/>,

## Commands

```bash

`mise run site:build -- --content <repo dir> --channel release|next --site-root /moonspec/ --release-version vX.Y.Z --ref <git ref> --out <dir>`

## Packages

| Package | Job |
|---|---|
| `route` | Route ADT, base paths |
| `content` | page manifest (publish allowlist, sidebar order) |

| `shell` | the rabbita component: model, update, views |
| `app` | browser entry: hydrates the pre-rendered page |
| `prerender` | native: renders every route, writes content copies and the search index |
| `linkcheck` | native: checks links, routes and the search index of a build |
````
