# Synchronous Wasm-GC calculator

This example uses the normal `moonrockz/moonspec` root package. Its three
ordinary tests are generated by the real CLI. Each test calls
`run_or_fail_sync` with the complete embedded feature source, including the
background and outline. There is no async package or test-driver import.

These APIs are unreleased pre-1.0 changes. Use this repository checkout and its
local `moon.work`, rather than the published 0.11.0 package. The dependency
version in `moon.mod` is resolved to this checkout by that workspace. Tested
with moon/moonrun 0.1.20261012 and moonc/core 0.10.15+943464bfa.

From the repository root:

```sh
mise run examples:sync-wasm -- wasm-gc
```

This builds the local CLI, regenerates the tests and executes exactly three
passing tests. To run all four supported synchronous targets:

```sh
mise run examples:sync-wasm
```

The task uses this CLI command from `examples/sync-wasm`:

```sh
../../_build/bin/moonspec gen tests features/calculator.feature \
  -w CalculatorWorld -o src --execution sync
```

`moonspec.json5` also selects `execution: "sync"`. The explicit flag wins over
merged configuration. Execution is independent of the per-scenario/per-feature
mode and white-box/black-box test kind. Async remains the generator default.

After generation, the tests do not read `features/calculator.feature`. The
source path is retained for diagnostics and Cucumber Messages, while its full
content lives in `FeatureSource::Text`. Editing the feature requires
regeneration. `Text` and `Parsed` avoid source reads; `File` and formatter file
output depend on the host. A browser or raw Wasm embedder must still provide
the standard MoonBit host ABI used by the program, including console output.
This example does not provide a browser filesystem.

The nested workspace excludes the other examples' optional async dependencies
on Wasm-GC. The parent `examples/moon.work` also includes this example for the
shared JavaScript example checks. For an executable async example, see
[calculator](../calculator/), which imports `moonrockz/moonspec/async` as
`@moonspec` and retains `run_or_fail` and async tests.
